# DotTeach
DEPI final garduation project main repository.

**DotTeach** is an online learning platform where instructors publish video courses, and students enroll, learn, take quizzes, track their progress and earn verifiable certificates. It is the graduation project of the **DEPI (Digital Egypt Pioneers Initiative) - Full Stack .NET** track, group **SWD5_S4**.

## Planned Features

- Student, Instructor and Administrator roles
- Course catalogue with search and filters
- Instructor dashboard: courses, sections, lessons and secure video upload
- Free and paid courses (Stripe test mode)
- Progress tracking and quizzes
- PDF certificates with public verification
- Admin panel: user management, course approval, analytics

## Technology (planned)

ASP.NET Core MVC, Entity Framework Core, SQL Server, ASP.NET Core Identity, Azure Blob Storage, Stripe, Bootstrap 5, jQuery, Video.js, Chart.js, iTextSharp. Architecture: N-Tier with Repository and Unit of Work patterns.

## Repository Workflow

- `main` holds reviewed, working work only.
- New work is done on `feature/<module>-<description>` or `docs/<topic>` branches and merged through pull requests reviewed by another member.
- Commit messages are short, meaningful and in the imperative.
